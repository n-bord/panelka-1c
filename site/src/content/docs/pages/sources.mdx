На панель можно добавить не только списки документов и справочников. Источники
позволяют использовать уже открытые формы, избранное 1С, веб-адреса, сохранённые
ссылки панели, дополнительные отчёты и обработки, локальные файлы и команды платформы.

Перед добавлением выберите страницу и колонку. В обычном интерфейсе объект переносится
в колонку перетаскиванием, в веб-интерфейсе добавляется кнопкой «+». Пошаговый пример
см. в статье [«Страницы, колонки и ссылки»](../create-page/).

## Какие объекты 1С поддерживаются

В источнике «Метаданные» доступны следующие категории. Конкретный набор зависит
от объектов, которые есть в вашей конфигурации.

| Группа | Поддерживаемые категории |
| --- | --- |
| Работа с данными | Справочники, документы, журналы документов, отчёты, обработки |
| Планы и регистры | Планы видов характеристик, планы счетов, планы видов расчёта, планы обмена, регистры сведений, регистры накопления, регистры бухгалтерии, регистры расчёта |
| Формы и настройки | Общие формы, константы, внешние источники данных |
| Задачи и процессы | Бизнес-процессы, задачи |

В зависимости от объекта ссылка может открывать список, отчёт, обработку или форму.
Чтобы открыть не список, а конкретный документ или элемент справочника, используйте
избранное, открытое окно, расширенный выбор или вставку внутренней навигационной ссылки 1С.

<Note>
Панелька не изменяет права доступа 1С. Наличие ссылки на панели не подтверждает доступ к её объекту. Открытие выполняется с правами текущего пользователя и может быть отклонено конфигурацией.
</Note>

## Основные источники

| Источник | Что содержит и когда использовать |
| --- | --- |
| Метаданные | Объекты текущей конфигурации по перечисленным выше категориям. Подходит для постоянных ссылок на списки, отчёты и формы |
| Избранное | Ссылки, которые пользователь уже добавил в избранное 1С. Можно отфильтровать списки и отчёты или конкретные объекты |
| Открытые / Открытые окна | Формы, открытые в текущем сеансе 1С. Удобно открыть нужный документ, элемент или отчёт и сразу добавить его на панель |
| Каталог панели | Уже добавленные ссылки текущей панели. Позволяет повторно разместить ссылку с её названием и подсказкой в другой колонке |
| Дополнительные отчёты и обработки | Внешние инструменты, зарегистрированные в базе через механизм БСП или WMS |
| Стандартные инструменты | Команды платформы 1С, которые можно разместить рядом с рабочими ссылками |

Если нужный документ или элемент уже открыт, источник «Открытые» избавляет от ручного
копирования навигационной ссылки. Если ссылка уже есть на панели, ищите её в каталоге
панели, а не создавайте заново.

## Что находится в «Ещё источники»

«Ещё источники» — это не отдельный тип объекта, а набор дополнительных способов
добавления ссылок в активную колонку.

Веб-редактор показывает дополнительные способы добавления в блоке слева.
В обычном редакторе откройте меню **«Источник»** и выберите **«Ещё источники»**:
появятся поля внутренней ссылки, веб-ссылки и выбора колонки. Названия ниже описывают
назначение источников; они не означают одинаковое меню в двух режимах.

### Вставить ссылку

Принимает веб-адрес сайта или внутреннюю навигационную ссылку 1С. Подходит для внешних
сервисов, конкретных документов, элементов справочников и других объектов, у которых
есть ссылка `e1cib/...`.

### Каталог панели

Показывает ссылки, уже сохранённые в панели. Выберите нужную запись, чтобы использовать
её повторно в активной колонке.

### Закладки браузера

Позволяет добавить веб-ссылки из закладок Chrome, Яндекс Браузера, Edge, Opera,
Brave и Vivaldi.

- **Windows:** поддерживается автоматический поиск закладок в профилях браузеров.
- **macOS:** используйте ручной импорт HTML-файла закладок или файла закладок Chromium
  в формате JSON.

### Внешние файлы

Добавляет локальные внешние обработки и отчёты в форматах `.epf` и `.erf`. Файлы можно
выбрать по одному, списком или загрузить ссылки из папки. Ограничения и рекомендации
для общей панели описаны [ниже](#локальные-отчёты-и-обработки).

### Дополнительные отчёты и обработки

Открывает выбор инструментов, уже зарегистрированных в базе через подсистему
«Дополнительные отчёты и обработки» БСП или совместимый механизм WMS. Их доступность
определяется настройками регистрации и правами пользователя.

Этот источник отличается от внешних файлов: здесь не нужен путь к EPF/ERF на компьютере,
поскольку обработка или отчёт уже подключены в информационной базе.

### Стандартные инструменты

Позволяет выбрать команды платформы 1С для активной колонки. Если стандартные инструменты
вынесены на отдельную вкладку в дополнительных настройках, их колонка назначается автоматически.

### Расширенный выбор

Открывает обычную форму выбора 1С со всеми поддерживаемыми типами метаданных. Используйте
его, когда удобнее найти объект через стандартный диалог платформы, а не через список источников.

## Локальные отчёты и обработки

Панелька сохраняет **путь к файлу**, а не его содержимое. Поэтому после добавления
файл должен оставаться по этому пути на компьютере пользователя, который открывает ссылку.

Для личной панели можно использовать файл на своём компьютере. Для общей панели,
которой пользуется команда, разместите EPF/ERF в общей сетевой папке и убедитесь, что:

1. сетевая папка доступна с рабочего места каждого пользователя;
2. сохранённый в Панельке путь одинаково открывается на их компьютерах;
3. у пользователей есть права операционной системы на чтение и запуск файлов;
4. у пользователей есть соответствующее право 1С на интерактивное открытие внешних файлов.

<Warning title="Если путь недоступен, ссылка не откроется">
Файл с локального диска администратора не становится автоматически доступным остальным
пользователям. Без подключённой сетевой папки, нужных прав или файла по сохранённому пути
такая ссылка будет неработоспособной у пользователя.
</Warning>

Добавляйте только доверенные файлы `.epf` и `.erf`: локальные инструменты подключаются
с отключённым безопасным режимом. Не используйте файлы из неизвестных источников.
Если локальные файлы не нужны в личных панелях, администратор может запретить этот источник.

<Note variant="tip" title="Что выбрать для команды">
Если конфигурация поддерживает подсистему «Дополнительные отчёты и обработки», для общего
доступа обычно удобнее зарегистрировать инструмент в базе и добавить его из соответствующего
источника. Тогда не потребуется поддерживать общий сетевой путь на каждом рабочем месте.
</Note>

## Ограничения персональных панелей

Администратор может разрешить или запретить для личных панелей отдельные категории
метаданных, стандартные инструменты, дополнительные отчёты и обработки, веб-ссылки
и локальные файлы. Поэтому набор источников у пользователя может отличаться от описанного
выше. Настройка описана в статье [«Личные панели: доступ и управление»](../../settings/personal-panel-admin/).

После переноса раскладки в другую базу проверьте ссылки, роли страниц и локальные пути.
XML переносит структуру и ссылки, но не сами EPF/ERF и не объекты другой базы. Подробнее —
в разделе [«Импорт и экспорт»](../../settings/import-export/).
