Перенос настроек выполняется через XML-файл. Экспорт пригодится для резервной
копии и переноса раскладки, импорт — для восстановления сохранённых настроек.

Чтобы познакомиться с импортом на примере, скачайте
[демонстрационную настройку в УТ 11](../../ut-example/#скачать-и-загрузить).

## Перед переносом

Откройте редактор той панели, с которой хотите работать: общей или своей личной.
Для общей настройки нужен администратор; импорт и экспорт личной панели могут быть
отдельно запрещены в [политике личных панелей](../personal-panel-admin/#дополнительные-разрешения).

Перед импортом экспортируйте текущую раскладку в отдельный XML — он понадобится для
возврата к прежнему варианту. Не перезаписывайте эту копию при следующей выгрузке.
При переносе между базами экспортируйте исходную панель, а XML загружайте в редактор
целевой панели. В обеих базах проверьте, выбрана ли нужная панель: общая или личная.

## Импорт из файла

Загрузка XML и запись настройки в базу — разные действия. Сначала проверьте получившуюся
структуру в редакторе, затем сохраните её. Для добавления одной ссылки удобнее использовать
[обычное наполнение колонки](../../pages/create-page/).

## Что переносится вместе с раскладкой

XML содержит структуру страниц, колонок и ссылки, но не переносит сами внешние
EPF/ERF, права доступа и объекты информационной базы. После загрузки в другую базу
проверьте навигационные ссылки, роли страниц и пути к локальным файлам.

Локальные отчёты и обработки должны быть доступны пользователям по сохранённому пути.
Для общей панели можно использовать общую сетевую папку. Если файл недоступен,
соответствующая ссылка не откроется.
Подробнее см. [«Объекты и источники»](../../pages/sources/#локальные-отчёты-и-обработки).

## Проверка после импорта

- На рабочей панели появились ожидаемые страницы и колонки.
- Ссылки открывают нужные списки, документы и сайты, если они есть в раскладке.
- При переносе в другую базу доступны нужные объекты конфигурации и роли страниц.
- Пути к локальным EPF/ERF доступны пользователям целевой панели.

Ссылка на конкретный документ сохраняет его адрес, а не создаёт документ в новой базе.

Если результат не подходит, импортируйте ранее сохранённую копию и снова сохраните настройку.

<Note>
Экспорт XML сохраняет настройки Панельки. Для резервного копирования самой
информационной базы используйте предусмотренные для этого средства 1С.
</Note>
